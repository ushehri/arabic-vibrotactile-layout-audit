# tie-audit

`tie_audit.py` checks whether rounding to 10⁻⁹ before ranking changes any rank vector built from sleeve positions and distances (three ض codings), the articulatory codes and the linear baselines.
It supports the tie-handling statement in Section 3.4 and produced no table values; the audit found that only the ranking baselines B1 and B3 in `s5.5-rev` were affected, and those were corrected there.
It has no data dependencies and prints its result.
